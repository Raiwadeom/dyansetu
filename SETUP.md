# Setting up DnyanSetu

DnyanSetu is a Vite + React site deployed on Vercel. Three free services sit
behind it:

- **Supabase**: accounts (email + Google sign-in) and the database. Full
  walkthrough: **[SUPABASE-SETUP.md](SUPABASE-SETUP.md)**.
- **Cloudinary**: uploaded notes and files (below).
- **Resend**: RaktSetu alert emails (Part 4 of SUPABASE-SETUP.md).

Every key goes in `hac/.env.local` for local work and in Vercel → Settings →
Environment Variables for the live site. The full list, with comments, is in
[.env.example](.env.example). Until the Supabase keys are set, the app runs on
offline demo data and says so in a banner.

## Run it locally

```
npm install
npm run dev          # http://localhost:5173 — the /api functions run too
npm run build        # production build into dist/
```

## Checks

```
npm run test:upload  # upload signing refuses forged/expired sessions
npm run check:rls    # database security rules (needs the RLS_TEST_* logins)
```

## Cloudinary

### 1. Cloud name and API keys

From the Cloudinary dashboard:

- **Cloud name** — shown at the top. Goes in `VITE_CLOUDINARY_CLOUD_NAME`.
- **Settings → API Keys** — the **API Key** and **API Secret**. These go in
  `CLOUDINARY_API_KEY` and `CLOUDINARY_API_SECRET`, both **without** a `VITE_`
  prefix so they stay on the server.

> The API secret is the one genuinely sensitive value in this project. Anything
> with a `VITE_` prefix is compiled into the browser bundle; the secret must
> never be.

### 2. Create a SIGNED upload preset

**Settings → Upload → Upload presets → Add upload preset.**

| Setting | Value |
| --- | --- |
| Signing mode | **Signed** |
| Preset name | `dnyansetu_signed` |
| Folder | `dnyansetu` |
| Allowed formats | `pdf,jpg,jpeg,png,webp` |
| Max file size | `15000000` |

Signed mode is the important one. It means an upload is refused unless it
carries a signature generated by the server.

### 3. Allow PDF delivery

**Settings → Security → Restricted media types** → untick **PDF and ZIP files**.

New accounts block PDF delivery by default. Miss this and question papers upload
fine, then return 401 when a student clicks download.

## The administrator

One address, `smuiqac@gmail.com`, holds the admin role. The database enforces
it (`admin_email()` in `supabase/migrations/0001_core.sql`), so no one can make
themselves admin from the browser. To move the role, change that function,
re-run the migration, and update `ADMIN_EMAIL` in `src/App.jsx`.

## Deploying

Push to `main` on GitHub; Vercel builds and deploys automatically. A daily
Vercel cron (`/api/cron/daily`) keeps the free Supabase project awake, expires
old blood requests and applies RaktSetu's data-retention rules.
